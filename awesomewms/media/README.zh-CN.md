## 1. 登录与首次访问

### 默认账号

| 字段 | 值 |
|------|-----|
| 访问地址 | `http://127.0.0.1:8000/` |
| 用户名 | `admin` |
| 密码 | `admin123` |

`admin` 账号是超级管理员，拥有系统所有权限，不受权限体系限制。

### 登录步骤

1. 浏览器打开 `http://127.0.0.1:8000/`
2. 在登录页面输入用户名和密码
3. 点击 **登入** 按钮，自动跳转首页

### 登录后你会看到

首页包含以下内容：
- **系统概览**：KPI 卡片展示商品总数、库位总数、库存条目数、供应商数、客户数、本周入库/出库数
- **快捷操作**：8 个快捷入口卡片，一键跳转到任意 WMS 功能模块
- **最近动态**：最新的入库单/出库单时间线
- **仪表板预览**：今日入库/出库汇总 + 跳转完整仪表板的入口
- **低库存预警**：当有商品库存低于 10 时，首页显示醒目的黄色警告横幅

## 2. 基础数据配置

在创建出入库单据之前，请按以下顺序配置基础数据：

### 第一步 — 创建供应商

1. 从首页快捷操作或左侧菜单点击 **供应商**
2. 点击右上角 **新增** 按钮
3. 填写表单：
   - **供应商名称**：例如 "上海某某电子有限公司"
   - **联系人**：例如 "张三"
   - **联系电话**：例如 "138-0000-0000"
   - **地址**：例如 "上海市浦东新区张江路100号"
4. 点击 **提交**

### 第二步 — 创建客户

1. 从首页快捷操作或左侧菜单点击 **客户**
2. 点击 **新增** 按钮
3. 填写客户信息（字段与供应商相同）
4. 点击 **提交**

### 第三步 — 创建商品

1. 从首页快捷操作或左侧菜单点击 **商品管理**
2. 点击 **新增** 按钮
3. 填写表单：
   - **商品名称**：例如 "A型垫片-10mm"
   - **商品编码**：例如 "WGT-001"（唯一标识符）
   - **规格型号**：例如 "10mm x 50mm, 不锈钢材质"
   - **单位**：例如 "个"、"kg"、"箱"
   - **单价**：单位价格（数字）
   - **描述**：选填，备注信息
4. 点击 **提交**

### 第四步 — 创建库位（存储位置）

1. 从首页快捷操作或左侧菜单点击 **库位管理**
2. 点击 **新增** 按钮
3. 填写表单：
   - **库位编码**：例如 "A-01-01"（唯一位置编码）
   - **库位名称**：例如 "A货架-第1排-第1层"
   - **库位类型**：例如 "货架"、"托盘位"、"地面位"
   - **容量**：该位置最大存放数量
4. 点击 **提交**

> **提示**：在任何列表页面使用顶部的搜索框可以按关键字过滤数据。切换页面时数据会自动刷新。

## 3. 入库操作 (ASN)

### 创建入库单

1. 从首页快捷操作或左侧菜单点击 **入库单(ASN)**
2. 点击 **新增** 按钮
3. 填写表单：
   - **入库单号**：例如 "ASN-2026-001"（你的入库单据编号）
   - **入库类型**：例如 "采购入库"、"退货入库"、"调拨入库"
   - **预计到货时间**：选择预计到达的日期时间
   - **状态**：保持 **待处理** 即可（收货确认后会自动变更）
4. 点击 **提交**

### 添加入库明细（行项目）

1. 点击左侧菜单的 **入库明细**
2. 点击 **新增** 按钮
3. 填写表单：
   - **入库单 ID**：选择刚刚创建的入库单（输入数字ID）
   - **商品 ID**：选择要入库的产品
   - **库位 ID**：选择存放的库位
   - **数量**：入库数量
   - **批次号**：选填，用于批次追溯
4. 点击 **提交**
5. 对每个产品行重复以上步骤

### 确认收货（自动更新库存）

1. 进入 **入库单(ASN)** 列表页面
2. 找到要确认的入库单
3. 点击 **确认收货** 按钮（勾选图标）
4. 系统自动执行以下操作：
   - 在指定库位增加库存数量
   - 如果该库位没有该商品记录，自动创建新的库存记录
   - 将入库单状态变更为 **已确认**

> **重要**：确认收货后库存会自动增加。请在确认前仔细核对入库明细，确保数据准确。

## 4. 出库操作 (DN)

### 创建出库单

1. 从首页快捷操作或左侧菜单点击 **出库单(DN)**
2. 点击 **新增** 按钮
3. 填写表单：
   - **出库单号**：例如 "DN-2026-001"
   - **出库类型**：例如 "销售出库"、"调拨出库"、"退货供应商"
   - **预计到货时间**：预计发货的日期时间
   - **状态**：保持 **待处理**
4. 点击 **提交**

### 添加出库明细（行项目）

1. 点击左侧菜单的 **出库明细**
2. 点击 **新增** 按钮
3. 填写表单：
   - **出库单 ID**：选择刚创建的出库单
   - **商品 ID**：选择要出库的产品
   - **库位 ID**：选择从哪个库位拣货
   - **数量**：出库数量
4. 点击 **提交**

### 确认发货（自动扣减库存）

1. 进入 **出库单(DN)** 列表页面
2. 找到要确认的出库单
3. 点击 **确认发货** 按钮
4. 系统自动执行以下操作：
   - 从指定库位扣减库存数量
   - 将出库单状态变更为 **已确认**

> **重要**：如果出库数量超过当前库存，系统会自动扣减到零（不会出现负库存）。

## 5. 库存管理

### 查看库存

1. 从首页快捷操作或左侧菜单点击 **库存管理**
2. 库存列表显示所有库存记录，包含：
   - 商品名称和库位位置
   - 当前数量
   - 来源入库单（哪个 ASN 创建的这条库存）

### 低库存预警

- 仪表板首页会自动展示数量 **低于 10** 的商品
- 首页顶部会显示黄色预警横幅，告诉你有多少个商品库存不足
- 点击预警横幅可直接跳转到仪表板查看详情

### 库存变动

所有库存变动都必须通过入库单或出库单确认来触发。系统 **不支持手动调整库存**，以确保完整的审计追踪。

## 6. 采购订单

采购订单关联供应商和商品。

1. 从首页快捷操作或左侧菜单点击 **采购订单**

   - 填写数量和其他备注信息
4. 点击 **提交**

## 7. 用户与权限管理

### 权限模型

```
API 列表 → 权限条目 → 用户组（勾选权限） → 用户（加入用户组，继承权限）
```

权限粒度细化到 API 级别 — 每个实体的每个操作都有对应权限。

### 创建用户组并分配权限

1. 在左侧菜单（基础标签页）点击 **用户组**
2. 点击 **新增用户组** → 输入组名 → **提交**
3. 在列表中找到新组，点击 **盾牌/锁** 图标的 **设置权限**
4. 在弹窗中勾选该组需要的权限。建议的分组方式：
   - **仓库操作员**：ASN、ASN明细、DN、DN明细（创建、修改）
   - **库存管理员**：商品、库位、库存（全部增删改查）
   - **只读用户**：各实体的"列表"权限
5. 点击 **提交**

### 创建用户并分配给用户组

1. 在左侧菜单点击 **用户列表**
2. 点击 **新增用户** → 输入用户名 → **提交**（默认密码与用户名相同）
3. 找到新用户 → 点击 **团队** 图标 → 选择用户组 → **提交**
4. 可选：设置 **部门** 和 **修改密码**
5. **重要**：权限变更后用户需要 **退出重新登录** 才能生效（基于 JWT 机制）

### 锁定/解锁用户

- 点击 **锁定/解锁** 图标可以禁用用户登录
- 被锁定的用户无法访问系统

### 权限分类一览

| 分类 | 可用权限 |
|------|---------|
| 用户管理 | 创建用户、修改密码、设置用户组、设置部门、锁定/解锁、删除用户 |
| 用户组管理 | 创建用户组、修改名称、设置权限、删除 |
| 部门管理 | 创建部门、修改名称、删除 |
| 商品管理 | 创建、修改、删除、列表 |
| 库位管理 | 创建、修改、删除、列表 |
| 库存管理 | 创建、修改、删除、列表 |
| 供应商 | 创建、修改、删除、列表 |
| 客户 | 创建、修改、删除、列表 |
| 入库单 | 创建、修改、删除、列表 |
| 入库明细 | 创建、修改、删除、列表 |
| 出库单 | 创建、修改、删除、列表 |
| 出库明细 | 创建、修改、删除、列表 |
| 采购订单 | 创建、修改、删除、列表 |

## 8. 搜索与分页

### 搜索数据

- 每个列表页表格上方都有 **搜索输入框**
- 输入关键字后按 **回车**，系统会在该实体的所有文本字段中搜索
- 清空搜索框按 **回车** 可重置列表

### 分页

- 使用表格底部的 **分页控件** 切换页面
- 可以调整 **每页行数** 来显示更多或更少的记录
- 分页栏会显示总记录数

## 9. 修改与删除数据

### 修改记录

1. 点击任意行上的 **铅笔/编辑** 图标
2. 在弹出的对话框中修改字段
3. 点击 **提交** 保存更改

### 删除记录

1. 点击任意行上的 **垃圾桶/删除** 图标
2. 弹出确认对话框 — **此操作不可撤销**
3. 点击 **提交** 永久删除该记录

> **注意**：系统内部使用软删除机制，但已删除的记录在界面中不可见。如需恢复已删除数据，请联系管理员操作数据库。

## 10. 系统监控（IS_LAN 模式）

当服务器以 `IS_LAN=true` 启动时，左侧菜单会出现 **服务器** 标签页，包含以下监控页面：

| 页面 | 内容说明 |
|------|---------|
| CPU | 实时 CPU 使用率 + 历史曲线图 |
| Memory | 已用/空闲内存 + 交换空间使用情况 + 曲线图 |
| Disk | 各磁盘分区使用率统计 |
| Network | 网络收发字节数追踪 + 曲线图 |
| PID | 进程级内存和 CPU 使用情况 |
| PID Tree | 进程内存使用矩形树图 |
| Dashboard | 服务器健康状态综合面板 |

## 12. 常见问题 (FAQ)

### Q: 登录后看不到某些菜单项？
**A**：你的账号可能没有对应权限。请联系管理员为你的用户组分配所需权限，然后退出重新登录。

### Q: 为什么刚入库的商品还在低库存预警里？
**A**：预警阈值固定为 **10 个**。库存低于此数量的商品都会触发预警。确认入库单增加库存后预警会自动消失。

### Q: 可以不通过入库单/出库单直接修改库存吗？
**A**：不可以。所有库存变更必须通过入库单（入库）或出库单（出库）确认来执行，以确保完整的审计追溯。

### Q: 如何重置管理员密码？
**A**：在服务器上执行以下命令：
```bash
PYTHONPATH=. python bomiot/server/manage.py shell -c "
from django.contrib.auth import get_user_model
u = get_user_model().objects.get(username='admin')
u.set_password('新密码')
u.save()
"
```

### Q: 可以连接 MySQL 或 PostgreSQL 替代 SQLite 吗？
**A**：可以。编辑 `awesomewms/setup.ini`，修改 `[database]` 部分：
```ini
[database]
engine = mysql
name = 数据库名
user = 数据库用户
password = 数据库密码
host = 127.0.0.1
port = 3306
```

### Q: 团队成员离职了，怎么交接？
**A**：有以下选项：
1. **锁定账号**：在用户列表点击锁定图标，禁止登录但保留数据
2. **更换用户组**：将该用户移到权限更少的用户组
3. **修改密码**：重置密码后交给新同事使用（需要在用户管理中修改密码）
