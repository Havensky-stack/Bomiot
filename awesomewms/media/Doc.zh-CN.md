## 1. 系统概述

awesomewms 是基于 Bomiot 框架构建的全栈仓库管理系统（WMS），提供完整的仓库业务功能：商品管理、库位管理、库存跟踪、供应商/客户管理、采购订单、入库单 (ASN) 和出库单 (DN)。所有库存变动均通过 ASN/DN 确认触发，确保完整的审计追踪。

### 技术栈

| 层级 | 技术 |
|------|------|
| 后端框架 | Django 4.2+ / Django REST Framework |
| 前端框架 | Quasar v2 + Vue 3.4 + Pinia |
| 数据库 | SQLite（默认）/ MySQL / PostgreSQL |
| 认证 | JWT Token + API级别权限控制 |
| 图表 | ECharts 5 |
| 监控 | psutil（CPU、内存、磁盘、网络） |

## 2. 首次配置

### 启动服务器

```bash
cd Bomiot
conda activate wms
IS_LAN=true PYTHONPATH=. python bomiot/server/manage.py runserver 0.0.0.0:8000
```

浏览器打开 `http://127.0.0.1:8000/`。

### 默认管理员账号

| 字段 | 值 |
|------|-----|
| 用户名 | `admin` |
| 密码 | `admin123` |

`admin` 是超级管理员，绕过所有权限检查，可访问所有功能。

### 登录流程

1. 访问 `http://127.0.0.1:8000/`
2. 输入 `admin` / `admin123`
3. 点击 **登入**，跳转到首页

### 首页布局

登录后你会看到：

- **欢迎横幅** — 系统名称和描述
- **KPI 概览卡片** — 商品总数、库位总数、库存条目数、供应商数、客户数、本周入库数
- **低库存预警** — 当有商品库存低于 10 时显示黄色预警横幅
- **快捷操作** — 8 个快捷入口卡片，直达商品、库位、入库、出库、库存、供应商、客户、采购
- **最近动态** — 最近 5 条入库/出库操作时间线
- **仪表板预览** — 今日入库/出库汇总 + 跳转完整仪表板的按钮

## 4. 基础数据配置（分步指南）

创建出入库单据之前，请按以下顺序配置基础数据。下游数据依赖上游数据。

### 4.1 创建供应商

供应商是商品入库的来源。

1. 在侧边栏或首页快捷操作中点击 **供应商**
2. 点击右上角 **新增** 按钮
3. 在对话框中填写：
   - **供应商名称**：例如 "上海某某金属制品有限公司"
   - **联系人**：例如 "张伟"
   - **联系电话**：例如 "138-0000-1234"
   - **地址**：例如 "上海市浦东新区张江路100号"
4. 点击 **提交** — 新供应商出现在列表中

### 4.2 创建客户

客户是商品出库的去向。

1. 在侧边栏点击 **客户**
2. 点击 **新增**
3. 填写与供应商相同的字段（名称、联系人、电话、地址）
4. 点击 **提交**

### 4.3 创建商品

商品是仓库中流转的产品/物料。

1. 在侧边栏点击 **商品管理**
2. 点击 **新增**
3. 填写：
   - **商品名称**：例如 "不锈钢垫圈-10mm"
   - **商品编码**：例如 "WASHER-10MM-SS"（唯一标识符）
   - **规格型号**：例如 "外径20mm, 内径10mm, 厚度2mm, 304不锈钢"
   - **单位**：例如 "个"、"kg"、"箱"、"卷"
   - **单价**：单位价格，数字（例如 0.50）
   - **描述**：选填备注（例如 "用于A线装配，德国进口"）
4. 点击 **提交**

> 建议创建多个商品记录，以便测试完整业务流程。

### 4.4 创建库位（存储位置）

库位是存放商品的物理位置。

1. 在侧边栏点击 **库位管理**
2. 点击 **新增**
3. 填写：
   - **库位编码**：例如 "A-01-03"（货架-排-层 编号体系）
   - **库位名称**：例如 "A货架-第1排-第3层"
   - **库位类型**：例如 "货架"、"托盘位"、"地面位"、"冷库位"
   - **容量**：该位置最大存放数量（例如 500）
4. 点击 **提交**

> 先创建库位，再在入库明细中将商品分配到具体库位。

---

## 5. 采购订单

采购订单是向供应商发出的采购请求。

### 5.1 创建采购订单

1. 在侧边栏点击 **采购订单**
2. 点击 **新增**
3. 填写：
   - **订单编号**：例如 "PO-2026-001"（内部订单号）
   - 从下拉列表选择 **供应商** 和 **商品**
   - 输入数量及备注信息
4. 点击 **提交**

采购订单是参考单据 — 不会影响库存。库存仅在创建并确认 ASN 或 DN 时变动。

---

## 6. 入库操作 (ASN — 入库通知单)

ASN 记录商品进入仓库。

### 6.1 创建入库单

1. 在侧边栏点击 **入库单(ASN)**
2. 点击 **新增**
3. 填写：
   - **入库单号**：例如 "ASN-2026-001"（唯一入库单据编号）
   - **入库类型**：选择 "采购入库"、"退货入库" 或 "调拨入库"
   - **预计到货时间**：预计到货日期/时间
   - **状态**：保持 **待处理**（确认收货后自动变更）
4. 点击 **提交**

### 6.2 添加入库明细（行项目）

每个行项目指定什么商品、多少数量、放到哪个库位。

1. 在侧边栏点击 **入库明细**
2. 点击 **新增**
3. 填写：
   - **入库单 ID**：输入刚创建的 ASN 的数字 ID（例如 `1`）
   - **商品 ID**：输入商品的数字 ID（例如 `1`）
   - **库位 ID**：输入库位的数字 ID（例如 `1`）
   - **数量**：入库数量（例如 `100`）
   - **批次号**：选填，用于批次追踪
4. 点击 **提交**
5. 对订单中的每个商品行重复上述步骤

### 6.3 确认收货 — 自动更新库存

1. 回到 **入库单(ASN)** 列表页
2. 找到要确认的入库单
3. 点击 **确认收货** 按钮（勾选/√ 图标）
4. 系统提示成功消息："ASN confirmed and stock updated"

**自动执行的操作：**
- 如果该商品+库位已有库存记录 → 数量增加
- 如果不存在库存记录 → 自动创建新库存记录
- 入库单状态从"待处理"变为"已确认"

> **警告**：确认前请仔细核对所有入库明细。已确认的入库单无法从界面撤销。

---

## 7. 出库操作 (DN — 发货通知单)

DN 记录商品离开仓库。

### 7.1 创建出库单

1. 在侧边栏点击 **出库单(DN)**
2. 点击 **新增**
3. 填写：
   - **出库单号**：例如 "DN-2026-001"
   - **出库类型**：选择 "销售出库"、"调拨出库" 或 "退货供应商"
   - **预计到货时间**：预计发货日期
   - **状态**：保持 **待处理**
4. 点击 **提交**

### 7.2 添加出库明细（行项目）

1. 在侧边栏点击 **出库明细**
2. 点击 **新增**
3. 填写：
   - **出库单 ID**：DN 的数字 ID（例如 `1`）
   - **商品 ID**：商品的数字 ID
   - **库位 ID**：从哪个库位拣货的数字 ID
   - **数量**：出库数量（例如 `30`）
4. 点击 **提交**

### 7.3 确认发货 — 自动扣减库存

1. 回到 **出库单(DN)** 列表页
2. 找到要确认的出库单
3. 点击 **确认发货** 按钮
4. 系统提示成功消息："DN confirmed and stock updated"

**自动执行的操作：**
- 指定商品+库位的库存数量减少
- 如果出库数量超过现有库存，数量截断为零（不会出现负数）
- 出库单状态从"待处理"变为"已确认"

## 8. 库存管理

### 8.1 查看库存

1. 在侧边栏点击 **库存管理**
2. 表格显示：
   - **商品名称** — 哪个产品
   - **库位编码** — 存放在哪里
   - **数量** — 当前在手数量
   - **来源入库单** — 哪个入库单创建了该库存

### 8.2 低库存预警

- 仪表板和首页会在任何商品 **数量低于 10** 时显示黄色预警横幅
- 横幅显示受影响的商品数量："8 个商品库存不足 10，请及时补货"
- 点击横幅或进入 **WMS 仪表板** 查看完整低库存列表

### 8.3 库存审计追踪

每次库存变更都由 ASN 或 DN 确认触发。系统 **不支持手动调整库存** — 确保完整的审计追溯。追踪库存变更：
- 找到库存记录 → 记录商品 ID 和库位 ID
- 在入库明细中搜索该商品+库位组合 → 追溯到对应的 ASN
- 在出库明细中搜索 → 追溯到对应的 DN

## 9. 仪表板与分析

### 9.1 WMS 仪表板

通过 WMS 标签页或首页按钮进入 **仪表板**。

仪表板展示：
- **KPI 卡片**：商品总数、库位总数、库存条目数、供应商数、客户数
- **出入库图表**：堆叠柱状图对比今日和本周的入库/出库数量
- **低库存列表**：数量 < 10 的商品列表

### 9.2 数据刷新

数据在以下情况下自动刷新：
- 切换语言（中文 ↔ English）
- 登录/登出导致 token 变更
- 导航到仪表板页面

## 10. 用户与权限管理

### 10.1 权限架构

```
API 端点 → 权限条目 → 用户组（分配权限） → 用户（加入用户组，继承权限）
```

权限粒度细化到 API 级别 — 每个实体的每个操作都有对应的权限。

### 10.2 权限分类一览

| 分类 | 可用权限 |
|------|---------|
| 用户管理 | 创建用户、修改密码、设置用户组、设置部门、锁定/解锁、删除用户 |
| 用户组管理 | 创建用户组、修改名称、设置权限、删除用户组 |
| 部门管理 | 创建部门、修改名称、删除部门 |
| 商品管理 | 列表、创建、修改、删除 |
| 库位管理 | 列表、创建、修改、删除 |
| 库存管理 | 列表、创建、修改、删除 |
| 供应商 | 列表、创建、修改、删除 |
| 客户 | 列表、创建、修改、删除 |
| 入库单 | 列表、创建、修改、删除 |
| 入库明细 | 列表、创建、修改、删除 |
| 出库单 | 列表、创建、修改、删除 |
| 出库明细 | 列表、创建、修改、删除 |
| 采购订单 | 列表、创建、修改、删除 |

### 10.3 创建用户组并分配权限

1. 在侧边栏（基础标签页）点击 **用户组**
2. 点击 **新增用户组** → 输入名称如 "仓库操作员" → **提交**
3. 找到新用户组 → 点击 **盾牌/锁** 图标（设置权限）
4. 在权限对话框中勾选需要的权限。建议分组：

   **仓库操作员**：入库单（创建、修改、列表）、入库明细（全部）、出库单（创建、修改、列表）、出库明细（全部）、库存（列表）

   **库存管理员**：所有 WMS 实体（商品、库位、库存 — 全部增删改查）

   **采购专员**：供应商（全部）、客户（全部）、采购订单（全部）

   **只读/审计**：所有实体仅勾选"列表"权限

5. 点击 **提交**

### 10.4 创建用户并分配给用户组

1. 在侧边栏点击 **用户列表**
2. 点击 **新增用户** → 输入用户名（例如 "operator01"）→ **提交**
   - 默认密码 = 你输入的用户名
3. 找到新用户 → 点击 **团队/人** 图标（设置用户组）
4. 选择用户组（例如 "仓库操作员"）→ **提交**
5. （可选）点击 **建筑** 图标设置部门
6. （可选）点击 **钥匙** 图标修改密码

### 10.5 权限重要提示

- **需重新登录**：修改用户组或权限后，用户必须退出并重新登录。权限在登录时嵌入 JWT token。
- **超级用户绕过**：`admin` 账号的 JWT 包含 `admin: true`，绕过所有权限检查。
- **锁定用户**：点击锁图标阻止用户登录。锁定/解锁即时生效。

### 10.6 部门管理

1. 在侧边栏点击 **部门管理**
2. 点击 **新增部门** → 输入名称（例如 "物流部"）→ **提交**
3. 部门是组织标签 — 不影响权限
4. 给用户分配部门：用户列表 → 点击部门图标 → 选择部门

## 11. 文件管理

### 11.1 上传中心

上传中心用于将文件上传到服务器。

1. 在侧边栏（基础标签页）点击 **上传中心**
2. 点击 **增加上传文件** 从电脑选择文件
3. 点击 **上传服务器** 开始上传
4. 每个文件显示上传状态：挂载 → 上传中 → 上传成功
5. 点击 **终止上传** 取消进行中的上传
6. 点击 **删除** 从列表中移除文件
7. **清空所有** 移除列表中所有文件

> 最大文件大小可在 `awesomewms/setup.ini` 的 `[file] file_size` 中配置（默认 102400000 字节 ≈ 97MB）。

### 11.2 文件中心（文件分享）

文件中心用于浏览、下载和分享已上传的文件。

1. 在侧边栏（基础标签页）点击 **文件中心**
2. 列表显示所有已上传文件，包含文件名、类型、大小、所属
3. **下载**：点击下载图标将文件保存到本地
4. **分享**：点击分享图标 → 选择要分享给的用户
5. **删除**：点击垃圾桶图标 → 确认后永久删除文件

## 13. 系统监控（服务器标签页）

当服务器以 `IS_LAN=true` 启动时，可以使用实时硬件监控页面。

### 13.1 CPU 监控

显示 CPU 型号、物理/逻辑核心数、当前/最小/最大频率、实时使用率百分比及历史时间线图表。

### 13.2 Memory 监控

显示总/已用/空闲内存、交换空间使用情况，以及内存使用率时间线图表。

### 13.3 Disk 监控

显示所有挂载分区，包括设备路径、挂载点、总/已用/空闲容量、使用率百分比。

### 13.4 Network 监控

显示字节发送/接收计数及网络吞吐量时间线图表。

### 13.5 PID 监控

列出所有运行中的进程，包含 PID、进程名称、内存使用量、CPU 使用率。

### 13.6 PID Tree

进程内存消耗的矩形树图 — 矩形越大 = 内存使用越多。

### 13.7 DashBoard

服务器健康状态综合面板。

## 14. 数据操作

### 14.1 搜索

每个列表页表格上方都有搜索输入框：
- 输入关键字后按 **回车** 过滤结果
- 搜索在所有文本字段中执行（使用大小写不敏感的包含匹配）
- 清空搜索框按 **回车** 显示全部记录

### 14.2 分页

- 使用表格底部的控件切换页面
- 调整 **每页行数** 显示更多或更少记录
- 分页栏显示总记录数

### 14.3 修改记录

1. 点击任意行上的 **铅笔/编辑** 图标
2. 在弹出的对话框中修改字段
3. 点击 **提交** 保存

### 14.4 删除记录

1. 点击任意行上的 **垃圾桶/删除** 图标
2. 弹出确认对话框："删除数据不可逆，请确认操作"
3. 点击 **提交** 永久删除

> **注意**：系统内部使用软删除（`is_delete` 标记）。已删除的记录在界面中不可见，但数据库中仍然保留。数据库级恢复需要管理员操作。

## 17. 配置参考

编辑 `awesomewms/setup.ini` 自定义系统行为：

```ini
[project]
name = awesomewms              # 项目标识

[database]
engine = sqlite                # sqlite, mysql, postgresql 或 oracle
name = 数据库名
user = 数据库用户
password = 数据库密码
host = 数据库主机
port = 数据库端口

[jwt]
user_jwt_time = 1000000        # JWT token 过期时间（秒）

[request]
limit = 5                      # 登录失败锁定次数

[file]
file_size = 102400000          # 最大上传文件大小（字节，约97MB）
```

修改数据库配置后需重启服务器。

## 19. 常见问题 (FAQ)

### Q: 登录后看不到某些菜单项？
你的账号缺少对应权限。请管理员：
1. 进入用户组列表 → 找到你的用户组 → 设置权限 → 勾选需要的权限
2. 然后你必须退出并重新登录（JWT token 刷新）

### Q: 为什么刚入库的商品还在低库存预警里？
预警阈值为 10 个。确认入库单增加库存后即可超过阈值。

### Q: 可以不通过入库单/出库单直接修改库存吗？
不可以。所有库存变更必须通过 ASN 确认（入库）或 DN 确认（出库）执行，以确保完整的审计追溯。

### Q: 登录失败 — 一直提示 "Please Login First"。
可能原因：
- JWT token 已过期（检查 setup.ini 中的 `user_jwt_time`）
- 账号被管理员锁定（检查用户列表 → 锁定状态）
- 浏览器缓存了过期 token — 清除浏览器缓存后再试

### Q: 如何重置管理员密码？
```bash
PYTHONPATH=. python bomiot/server/manage.py shell -c "
from django.contrib.auth import get_user_model
u = get_user_model().objects.get(username='admin')
u.set_password('新密码')
u.save()
"
```

### Q: 服务器标签页（CPU、Memory、Disk、Network）不显示。
使用 `IS_LAN=true` 环境变量启动服务器：
```bash
IS_LAN=true PYTHONPATH=. python bomiot/server/manage.py runserver 0.0.0.0:8000
```

### Q: 如何从 SQLite 切换到 MySQL？
1. 编辑 `awesomewms/setup.ini`：
```ini
[database]
engine = mysql
name = wms_db
user = root
password = 你的密码
host = 127.0.0.1
port = 3306
```
2. 在 MySQL 中创建数据库：`CREATE DATABASE wms_db CHARACTER SET utf8mb4;`
3. 重新运行迁移：`PYTHONPATH=. python bomiot/server/manage.py migrate`
4. 重新填充数据：运行 `seed_api.py` 和 `seed_permissions.py`
5. 重新创建管理员账号
6. 重启服务器

### Q: 搜索找不到数据。
搜索使用大小写不敏感的模糊匹配。技巧：
- 尝试更短的字符（例如搜索 "垫圈" 而不是 "不锈钢垫圈"）
- 确保输入后按了回车键
- 搜索仅适用于文本字段 — 数字 ID 需要精确匹配

### Q: ASN/DN 确认错误了怎么撤销？
界面中没有"撤销"按钮。作为管理员，你可以：
1. 创建一笔反向交易 — 用 DN 抵消错误的 ASN，或反之
2. 或作为最后的手段，通过 Django shell 直接修正数据库记录

### Q: 文件上传失败，没有错误提示。
检查：
- 文件大小是否超过 `setup.ini` 中的 `file_size` 限制
- 服务器磁盘空间是否已满
- 配置可能限制了特定的文件类型

### Q: 团队成员离职了怎么交接？
有以下选项：
1. **锁定账号**：在用户列表点击锁定图标，禁止登录但保留数据
2. **更换用户组**：将该用户移到权限更少的用户组
3. **修改密码**：重置密码后交给新同事使用

```
ASN-2026-001: 类型=采购入库, 状态=待处理

```

进入 **库存管理** → 验证：
- 库位A-01-01: M8钢螺栓 = 800
- 库位A-01-02: M8钢螺母 = 500

进入 **仪表板** → 验证 KPI 数据反映了新的业务记录。
